# soulred-social-platform - 交互原型规格说明书

## 1. 原型定位与设计目标
本原型旨在开发编码前，将产品需求规范（PRD）与竞品调研结论进行**1:1 可视化具象呈现**，供用户、产品经理与架构师在进入大规模代码开发前进行闭环人机协同决策。

- **原型文件**: `docs/PROTOTYPE.html`
- **体验模式**: 单文件自包含高保真交互，支持任意主流现代浏览器双击或在线直接运行。
- **技术基础**: Tailwind CSS + Lucide Icons + 响应式双列瀑布流 / 选项卡状态机。

---

## 2. 竞品标杆交互吸收与差异化还原
- 标杆 [小红书 (RED)]: 借鉴 双列瀑布流探索广场, 高分辨率图文详情浮层，差异化: 引入链上信誉鉴权与真实社交关系链评分，杜绝虚假人设与软广刷量
- 标杆 [Soul App]: 借鉴 兴趣契合度算法匹配, 即时破冰与亲密度成长体系，差异化: 去中心化隐私加解密与零知识证明，保障个人偏好与聊天记录绝对隐私
- 标杆 [Linear / Notion]: 借鉴 全局暗色高对比度现代设计语言, 无缝轻量状态机与微交互动效，差异化: 结合青年潮酷视觉与专业级数据隔离架构

---

## 3. 核心交互场景与点击动线
1. **主广场 / 视图切换**：支持顶部导航栏、风格分类标签动态高亮与数据联动筛选。
2. **卡片视觉与微交互**：支持卡片自适应高度、鼠标悬浮微动画、即时点赞与数字自增。
3. **沉浸式详情弹窗**：点击卡片可触发大图详情浮层，支持全屏预览、作者信息展示与评论区交互。
4. **人机确认机制**：用户可随时在主控制台提交修改意见，或点击“确认原型”正式开启架构与后端编码。
